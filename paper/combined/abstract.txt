We investigate whether correct values remain recoverable from a language model's internal activity when misleading names lead it to report wrong calculations. Building on Kudo et al. (2026), we change variable names in arithmetic problems and Python programs while keeping their computations fixed. In code, a name suggesting summation can make a model report the sum of a list where the program computes its length. On these incorrect intermediate outputs in three tested code models, a separately trained predictor recovers the correct digit with 95.5–99.7% accuracy immediately before the model reports the wrong digit. Showing the operation alongside its result in worked examples improves both intermediate and final correctness. On the same misleading-name programs, OLMo-2-7B's final-answer accuracy rises from 37.1% to 92.6%. Examples that explicitly connect each value to its computation offer a practical way to improve written reasoning.

# Misleading Identifiers Change What Code Traces Write

Cue conflict in code: does a misleading identifier survive the chain? Follow-up to
[NietZteiN/probing](https://github.com/NietZteiN/probing). Plan in [PLAN.md](PLAN.md); pre-registered claims in [PREREGISTRATION.md](PREREGISTRATION.md); related work in [RELATED_WORK.md](RELATED_WORK.md).

`make test` runs the generator rule tests; `make data` builds the datasets (CPU, seconds).

The revised manuscript follows the naming effect, patching interventions, and the change
from values-only to expression-bearing examples. The verification pass found train/test
program overlap in the original probes. Validated disjoint reruns now supply the paper's
readouts; the original caches remain available for auditing. Its
argument and interpretation limits are in [paper/ARGUMENT.md](paper/ARGUMENT.md).

# Submission checks

Checked against [ARR's author checklist](https://aclrollingreview.org/authorchecklist),
[CFP](https://aclrollingreview.org/cfp), [formatting rules](https://acl-org.github.io/ACLPUB/formatting.html)
and [Responsible NLP guidance](https://aclrollingreview.org/responsibleNLPresearch/) on October 10, 2026.

- [x] Anonymous ACL review format, unmodified official style, A4, embedded fonts and line numbers.
- [x] Four pages including the complete Limitations section, honoring the requested stricter limit.
- [x] References and necessary appendices in the same PDF; appendices retain two columns.
- [x] Numbers, denominators, confidence intervals and scientific qualifications checked.
- [x] Related work distinguishes the arithmetic and code contributions; reciprocal anonymous citations.
- [x] No author identifiers, identifying repository links, acknowledgments or unfinished text in the PDF.
- [x] Clean source archive contains only manuscript dependencies; standalone compilation verified.
- [x] Plain-text title, abstract and suggested submission fields prepared.
- [x] Companion anonymous PDF prepared for the concurrent-submissions field.
- [x] Responsible NLP answers include evidence and AI-assistance disclosure.

These author/account facts require completion in OpenReview. They cannot be certified from the manuscripts.

- [ ] Confirm the complete author list and order, submission history and absence of conflicting review.
- [ ] Verify every author's full OpenReview profile, including affiliation, ORCID and conflicts.
- [ ] Choose a qualified designated service contributor and complete the required registration.
- [ ] Confirm the preprint declaration and any existing public preprint URLs.
- [ ] Review and enter the Responsible NLP answers, then upload the paper and concurrent-paper attachment.

The source ZIP is a LaTeX handoff, not a research software/data release. The PDFs do not promise
reviewer access to an unavailable repository. Any later software/data supplement needs an
anonymous package, documentation and an author-approved distribution license.
